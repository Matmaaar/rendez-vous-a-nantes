# Guide d'utilisation pour l'équipe

Le document que liront les personnes qui font vivre le site au quotidien (communication, rédaction), sans connaissance technique. Il est à produire avant la mise en ligne et à remettre avec le site.

## Principes

- Écrit pour quelqu'un qui n'a jamais ouvert WordPress : phrases courtes, chemins de menus exacts (« Pages → Toutes les pages → survoler → Modifier »), aucun mot technique non expliqué.
- Organisé par **tâche**, pas par fonctionnalité : « Je veux… changer une photo », pas « Les champs image ».
- Une capture d'écran annotée par tâche quand c'est possible (prises sur l'environnement de test).
- Sobre : titres clairs, listes numérotées, un encadré « Attention » seulement quand une erreur est coûteuse. Pas de charte graphique imposée ; reprendre celle du client seulement s'il la fournit.
- Format au choix de l'utilisateur : document partageable, page HTML, PDF. Demander.

## Sommaire type

1. **Comment est fait le site** (une demi-page) : les rubriques, les types de fiches, ce qui se modifie dans l'admin et ce qui demande un développeur.
2. **Se connecter** et repérer les menus utiles.
3. **Modifier un texte** d'une page ou d'une fiche.
4. **Changer une photo** (formats et tailles conseillés, texte alternatif : décrire ce qu'on voit, en une phrase).
5. **Ajouter / retirer / réordonner une fiche** ou une case dans une liste.
6. **Modifier un bouton ou un lien.**
7. **Traduire** : où trouver la version dans une autre langue, ce qui est copié automatiquement et ce qui se traduit à la main.
8. **Publier, dépublier, programmer.**
9. **Ce qu'il ne faut pas faire** : changer de thème, supprimer des groupes de champs, mettre à jour les extensions sans sauvegarde, renommer l'adresse d'une page sans redirection.
10. **En cas de problème** : qui contacter, où est la sauvegarde, comment revenir en arrière.
11. **Aide-mémoire** d'une page : les 10 actions les plus fréquentes et leur chemin.

## Vérification

Faire relire le guide par une personne de l'équipe qui suit les étapes sur l'environnement de test sans aide. Chaque endroit où elle bloque est une étape à réécrire.
